# Continual Multimodal Learning with Episodic Memory

A research-oriented implementation of continual multimodal learning with
episodic memory mechanisms for mitigating catastrophic forgetting.

## Project Status

Now Work in progress.

This repository is being developed incrementally, with individual components
implemented, tested, and documented separately.

## Project Structure

- `data/` — datasets and preprocessing outputs
- `notebooks/` — exploratory experiments and analysis
- `src/` — core implementation
- `tests/` — unit and component tests
- `results/` — experimental results and figures
- `docs/` — technical documentation
